# JOLT: Jointly Optimized Layerwise Termination

Training objective and exit policy for budgeted early-exit inference.
The objective combines a cumulative product-of-experts likelihood,
final-to-early distillation, learned per-exit loss weighting, a per-exit
Brier anchor, and a final-exit cross-entropy anchor, with the balance
learned jointly. The exit policy calibrates per-exit exit fractions to a
stated compute budget on validation and holds them at test time with
running quantiles, so the deployed compute stays on budget under
distribution shift.

## Setup

```bash
pip install -r requirements.txt
```

Python 3.10, PyTorch 2.x, one CUDA GPU.

## Data

Place datasets under `data/`:

| Dataset | Source | Expected path |
|---|---|---|
| UCI-HAR | UCI repository | `data/UCI HAR Dataset/` |
| PAMAP2 | UCI repository, then `python scripts/build_pamap2_canonical.py` | `data/PAMAP2/canonical27/` |
| CIFAR-100 | auto-download | `data/` |
| GSC v2 | auto-download (torchaudio) | `data/` |
| SST-2 | auto-download (HuggingFace datasets) | `data/` |
| ESC-50 | github.com/karolpiczak/ESC-50 | `data/ESC-50/` |

Tiny-ImageNet-C under `data/corruptions/`; sensor, audio, and text
perturbations are generated by the evaluation scripts themselves.

## Training

`scripts/screen.py` trains one method on one dataset. The paper's
configurations, one per dataset:

| Dataset | Config | JOLT hyperparameters |
|---|---|---|
| UCI-HAR | `configs/ucihar_tst.yaml` | `gamma_distill=0.25 lambda_brier=0.15 lambda_ce=2.0` |
| PAMAP2 | `configs/pamap2_inceptiontime_canonical27.yaml` | `gamma_distill=8.0 lambda_brier=1.0` |
| CIFAR-100 | `configs/cifar100_convmixer_256_8.yaml` | `gamma_distill=2.0 lambda_brier=0.5 lambda_ce=4.0` |
| GSC v2 | `configs/gsc_v2_matchboxnet.yaml` | `gamma_distill=0.5 lambda_brier=0.5` |
| SST-2 | `configs/glue_sst2_bert_base_multiexit_e3612.yaml` | `gamma_distill=16.0 lambda_brier=0.5 lambda_ce=0.5` |
| ESC-50 | `configs/esc50_efficientnet_b0_v2.yaml` | `gamma_distill=16.0 lambda_brier=2.0` |
| Tiny-ImageNet | `configs/tinyimagenet_cct7.yaml` | `gamma_distill=2.0 lambda_brier=0.5` |

Example, CIFAR-100, three seeds of the JOLT configuration and one baseline:

```bash
for K in 0 1 2; do
  python scripts/screen.py \
    --config configs/cifar100_convmixer_256_8.yaml --data-root data \
    --candidates poe_distill_mtl_brier \
    --component gamma_distill=2.0 --component lambda_brier=0.5 --component lambda_ce=4.0 \
    --output-root outputs/cifar100 --base-seed $((42+K)) --seeds 1 \
    --variant-tag "g2.0-lb0.5-ce4.0_seed${K}" --skip-leaderboard
done
python scripts/screen.py \
  --config configs/cifar100_convmixer_256_8.yaml --data-root data \
  --candidates branchynet --output-root outputs/cifar100 \
  --base-seed 42 --seeds 3
```

Baseline method names: `adaloss branchynet eenet td meronen_laplace
ztw_cascade beem jei_dnn poe_jazbec boostnet`. Every method trains with
its published recipe; per-exit thresholds are never tuned on test data.

## Evaluation

Budgeted-batch protocol (thresholds solved on validation for each
budget, test accuracy reported at the selected level):

```bash
python scripts/budgeted_eval.py --cell CIFAR-100
```

Distribution shift (per modality) and operating-point calibration:

```bash
python scripts/shift_eval.py --cell CIFAR-100          # corruptions
python scripts/sensor_shift_eval.py --cell UCI-HAR     # IMU perturbations
python scripts/audio_shift_eval.py --cell ESC-50       # SNR ladders
python scripts/text_shift_eval.py                      # typos, domain
python scripts/opcal_eval.py --cell CIFAR-100          # ECE / NLL
```

## Leave-one-out ablation

Retrain with one term removed at the same hyperparameters, writing to the
dataset's `_loo` root, for example on CIFAR-100:

```bash
for ARM in poe_multitask_brier poe_distill_brier poe_distill_mtl; do
  for K in 0 1 2; do
    python scripts/screen.py \
      --config configs/cifar100_convmixer_256_8.yaml --data-root data \
      --candidates $ARM \
      --component gamma_distill=2.0 --component lambda_brier=0.5 --component lambda_ce=4.0 \
      --output-root outputs/cifar100_loo --base-seed $((42+K)) --seeds 1 \
      --variant-tag "g2.0-lb0.5-ce4.0_seed${K}" --skip-leaderboard
  done
done
```

`poe_multitask_brier` removes distillation, `poe_distill_brier` removes
the learned weighting, `poe_distill_mtl` removes the Brier anchor.
